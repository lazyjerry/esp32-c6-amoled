## 關鍵問題
1. MicroPython 支援 ESP32-C6 嗎？→ 已答：官方正式支援，v1.28.0（2026-04-06）。
2. 有現成的 SH8601 MicroPython 驅動嗎？→ 已答：只有 dobodu 那一份，**ESP32-S3 only、需客製韌體、不相容 LVGL**。
3. lvgl_micropython 能接這片面板嗎？→ 已答：內建 ~30 種驅動不含 sh8601，QSPI 未列正式支援；C6 可建置但示範用的是 SPI ST7789。
4. 記憶體撐得住嗎？→ 已答：C6 無 PSRAM、512KB SRAM；全畫面緩衝就要 322KB，再疊 MicroPython runtime 更緊。
5. 那還有什麼路？→ 已答：唯一路徑是自己寫 C module 包 `esp_lcd_sh8601`，等於為了用 Python 先多寫 C。

## 已做決策
- **先澄清再動手**：專案沒有自有 C++，「取代 cpp」有多種解讀，以選單確認範圍後才研究。

- **不預先寫驅動程式碼**：卡點未解除前寫 Python 週邊驅動是投機產出。
